# CFCA本計算の記録

本計算ごとに計算IDを付け、そのIDをファイル名にしたMarkdownで記録する。
計算IDはinput・ジョブスクリプトと統一する。

## 記録する項目

- 計算ID・目的
- Novaでの対応するテストと、本計算で変更した条件
- ソースのコミットID・タグ
- ビルド時の未コミット変更の有無
- 使用したビルドスクリプトとconfigureの引数
- コンパイラ・MPI・使用moduleの名前とバージョン
- 実行ファイルの保存先・SHA256
- 使用したinputと実行時の上書き引数
- ジョブスクリプト・ジョブID・使用キュー
- ノード数・MPIプロセス数・OpenMPスレッド数
- 実行日時・終了状況
- 結果の保存先
- 再スタートした場合は、元の計算と使用ファイル
- 結果・考察

計算結果と再スタートファイル自体はGitの管理外に保存する。
